# VIDRARCH // Brand Guide

## Identity

**Callsign:** VIDRARCH  
**Primary descriptor:** Security Systems Engineering  
**Primary line:** Architect. Defend. Endure.  
**Secondary line:** Strength without noise. Proof through engineering.

VIDRARCH is an invented name. The intent is to combine the restrained endurance associated with the Norse Víðarr story with **ARCH** as a modern reference to architecture, engineering, and building systems. Do not claim VIDRARCH is an authentic Norse word.

## What the brand should communicate

- disciplined engineering rather than hacker theater
- quiet competence rather than performative bravado
- architecture plus production ownership
- evidence and validation rather than unsupported claims
- resilience, recovery, and operational continuity
- technical depth that can still be understood by leadership

## Tone

Use language such as:

- architect
- validate
- operationalize
- evidence
- target state
- rollback
- telemetry
- trust
- resilience
- decision gate
- production assurance

Avoid language such as:

- elite hacker
- cyber ninja
- 10x
- god-tier
- unhackable
- master of everything
- military / intelligence claims that are not literally true

## Visual system

Primary background: `#071012`  
Deep panel: `#0D1B1F`  
Ice / telemetry accent: `#7FE7DC`  
Forge / architecture accent: `#D2A95B`  
Primary text: `#EDF6F4`  
Muted text: `#9DB0AE`

The design deliberately combines cold telemetry colors with a restrained forge/gold accent.

## Mark

The mark is an original angular **V** above an arch line. It is a geometric monogram, not an authentic rune or bind-rune. That distinction should be preserved.

## Naming hierarchy

Public technical brand:

```text
VIDRARCH // SECURITY SYSTEMS ENGINEERING
```

Professional identity:

```text
Ricardo Frontera
Junior Security Systems Engineer — IT Security
```

Recruiter-facing presentation should always make the real name and accurate current title easy to find. The callsign is a brand layer, not a replacement identity.

- [ ] Create/claim GitHub username `vidrarch`.
- [ ] Turn on passkey/hardware-backed MFA and recovery codes.
- [ ] Create repository `vidrarch.github.io` but keep it private until domains/handles are secured.
- [ ] Check and register `vidrarch.com`; consider defensive `.dev` / `.io` only if useful.
- [ ] Enable registrar lock, auto-renew, privacy/redaction, and DNSSEC where supported.
- [ ] Claim the matching handles you actually plan to use.
- [ ] Run a USPTO exact + similar-mark search and a broader common-law search.
- [ ] Preserve first-use evidence.
- [ ] Publish the site.
- [ ] Use `VIDRARCH™`, not ®.
- [ ] Schedule attorney review / federal word-mark filing if the brand is worth protecting long-term.

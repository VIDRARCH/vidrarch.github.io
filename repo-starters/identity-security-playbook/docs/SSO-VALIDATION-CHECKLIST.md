# SSO Validation Checklist

- [ ] Identifier / Entity ID confirmed
- [ ] Reply / ACS URL confirmed
- [ ] Sign-on behavior confirmed
- [ ] NameID format/value confirmed
- [ ] Required claims confirmed
- [ ] Signing certificate valid and trusted
- [ ] Test user scoped correctly
- [ ] Successful IdP sign-in confirmed
- [ ] Application-side identity mapping confirmed
- [ ] Authorization/entitlement confirmed separately
- [ ] Failure logs captured on both sides
- [ ] Rollback / break-glass access understood

# Production Security Change Checklist

## Pre-change
- [ ] Scope and product identity verified
- [ ] Target state documented
- [ ] Dependencies identified
- [ ] Backup / recovery path verified
- [ ] Pilot evidence reviewed
- [ ] Change window and owners confirmed
- [ ] Validation tests defined
- [ ] Rollback triggers defined

## During change
- [ ] Evidence captured
- [ ] Unexpected conditions assessed before continuing
- [ ] Stop/go gates honored

## Post-change
- [ ] Product/version/configuration confirmed
- [ ] Service health confirmed
- [ ] Security telemetry confirmed
- [ ] Business function confirmed
- [ ] Integrations confirmed
- [ ] Logs reviewed
- [ ] Recovery path retained until observation closes
- [ ] Evidence and closeout documented

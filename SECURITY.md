# Security Policy

This repository is a public professional portfolio. It must not contain production secrets, internal architecture, incident evidence, live credentials, or organization-specific defensive details.

If sensitive information is accidentally committed:

1. Remove the material from the working tree immediately.
2. Rotate/revoke any exposed secret or credential; deleting a Git commit is not sufficient.
3. Remove the sensitive material from Git history before republishing.
4. Treat screenshots and binary files as sensitive until reviewed.
5. Follow the affected organization's incident / exposure process where applicable.

Do not open a public GitHub issue containing the sensitive value itself.
